Selected work

Arthur

In production since July 2026

A service that handles everything between a confirmed booking and the guest walking in the door, for a short-term rental listed on Airbnb and VRBO.

It reads the booking confirmation email, then works through a checklist on its own: it sends the guest a DocuSign registration form, programs a time-limited code on the smart lock, adds the stay to the cleaning company's spreadsheet, and emails the signed form to the HOA inside the HOA's allowed window. Each task has its own state, so at any moment the system can say what has run, what is blocked, and why. A task is locked before it runs, so a button press and a scheduled job can never send the same form twice.

Every production change starts with a failing test. The offline test suite needs no credentials or network and runs in CI on every push.

Python, FastAPI, PostgreSQL, APScheduler, Docker, Dokploy

Source and write-up on GitHub

Argus

Early alpha, running on my own servers

Self-hosted monitoring for websites and scheduled jobs, in a single Go binary.

Argus checks HTTP endpoints, response content, TCP ports, ICMP reachability, and DNS answers, and it alerts when a scheduled job stops sending its heartbeat. It has a browser admin page, a REST API described in OpenAPI, a public status page, and Prometheus metrics. Every check result is written to an append-only record, so the history it shows can be trusted. It stores data in SQLite and needs no hosted account.

Go, SQLite, OpenAPI, Prometheus, Docker

The source is private for now.
